# Task 1 - Rule-Based Chatbot

A small command-line chatbot that detects common intents using keyword and regular-expression patterns and responds with predefined text.

## Run

```bash
python3 chatbot.py
```

Type `help` to see example prompts and `quit` to exit. Edit `INTENTS` in `chatbot.py` to add or change patterns and responses. This is an explainable rule-based NLP demonstration; it does not learn from data.
